Grimfall Bagnon

Bagnon, organized by level, for Grimfall

A small adaptation on top of the classic Bagnon (by Tuller), fixed to run on Grimfall's 3.3.5a client, with a level-based layout added on top to make gear organization easier while leveling.

Download .zip Straight from the GitHub repo — copy the Bagnon folder (required) plus Bagnon_Config, Bagnon_GuildBank, Bagnon_Tooltips, Bagnon_VoidStorage and Bagnon_Forever into AddOns.

What's added on top of stock Bagnon

Bags and bank are grouped into level bands (1-9, 10-19, 20-29... up to 60+) instead of one flat grid, and every item shows the level required to use it right on its icon.
Switch between the normal Bagnon view and the Level Group view. Stock Bagnon is still great for a lot of things, so you keep both instead of losing one for the other.
Cloth / Leather / Mail / Plate / Weapon 1H / Weapon 2H. Narrows the Level Group view to one gear type at a time, so comparing upgrades in one slot is easier.
The physical "clean items" sort button now follows the same level-band order when Level Group is on, instead of sorting against it.
Both toggle buttons live in the same left-side button row as the sort/search buttons, instead of the top-right corner. Skinning addons like DragonUI redraw that corner, which was hiding the buttons before.

Version history

v1.0Base fix + Level Group
  • Fixed stock Bagnon so it actually loads and runs on Grimfall's 3.3.5a client.
  • Added the Level Group layout: bags and bank grouped into level bands (1-9 up to 60+).
  • Added the required level shown on each item icon.
  • Added a one-click toggle between the normal Bagnon view and Level Group.
v1.1Equipment type filter
  • Added a filter (Cloth / Leather / Mail / Plate / Weapon 1H / Weapon 2H) to narrow the Level Group view to one gear type at a time.
v1.2Bug fixes + full addon suite
  • Found: switching back to the normal view left the level band headers stuck on screen. Fixed.
  • Found: sorting while in Level Group view left items looking randomly placed until the bag was closed and reopened. Fixed — the grouped view now updates in real time as items move.
  • Found: bag-skinning addons like DragonUI redraw the top-right corner, hiding our buttons there. Fixed — both buttons moved into the left button row instead.
  • Added the full companion addon suite to the download: Config, GuildBank, Tooltips, VoidStorage, Forever.
v1.3Dungeon-scaled item levels
  • Found: some dungeon-scaled items (the same item, dropped at a different level) showed in the wrong level band — their static item data stayed wrong even after a full client restart.
  • Fixed: now reads the real required level from the tooltip text itself when the game's stored item data disagrees with it.
v1.4Level badge toggle + combat safety
  • Requested: a way to hide the required-level number drawn on every item icon. Added: a new option, Show required level on item icons, in the addon options (type /bagnon) — or flip it on the fly with /bagnon badge. On by default.
  • Reported: bags not opening during combat. The exact cause is not confirmed yet, so this is a safety net: Bagnon now builds its own item buttons instead of borrowing the default bag ones, and if the game refuses to show the window mid-fight, the default bags open instead of nothing happening.
  • Added /bagnon debug — prints a short diagnostic so we can pin down the combat problem if it still happens for you.
All credit to Tuller and the Bagnon team for the original addon — this is just a small layer on top, adapted for Grimfall's 3.3.5a client.

Bagnon organizado por nível, pro Grimfall

Uma pequena adaptação em cima do Bagnon clássico (de Tuller), corrigido pra funcionar no cliente 3.3.5a do Grimfall, com uma visualização por nível adicionada por cima pra facilitar organizar o equipamento enquanto você sobe de nível.

Baixar .zip Direto do repositório no GitHub — copie a pasta Bagnon (obrigatória) e também Bagnon_Config, Bagnon_GuildBank, Bagnon_Tooltips, Bagnon_VoidStorage e Bagnon_Forever pra AddOns.

O que foi adicionado em cima do Bagnon original

Bolsas e banco são agrupados em faixas de nível (1-9, 10-19, 20-29... até 60+) em vez de uma grade única, e cada item mostra o nível necessário direto no ícone.
Troca entre a visão normal do Bagnon e a visão por nível. O Bagnon original continua ótimo pra muita coisa, então você fica com os dois em vez de perder um pelo outro.
Cloth / Leather / Mail / Plate / Weapon 1H / Weapon 2H. Reduz a visão por nível a um tipo de equipamento de cada vez, facilitando comparar upgrades de um slot.
O botão físico de "limpar itens" agora segue a mesma ordem por faixa de nível quando o modo Level Group está ativo, em vez de brigar com ele.
Os dois botões de alternância ficam na mesma fileira esquerda dos botões de organizar/busca, em vez do canto superior direito. Addons de skin como o DragonUI redesenham esse canto, o que escondia os botões antes.

  • Adicionado /bagnon debug — mostra um diagnóstico curto pra podermos achar o problema de combate caso ele ainda aconteça com você.
